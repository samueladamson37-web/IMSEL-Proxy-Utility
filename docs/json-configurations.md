# Готовые конфигурации серверов

Некоторые подписки передают готовые настройки сервера вместо обычных ссылок. Такие серверы обрабатываются особым образом для сохранения совместимости с настройками подписки.

## Как это работает

Когда подписка присылает готовую конфигурацию:

- Приложение **использует настройки из подписки** без изменений
- **Локальные настройки сервера не применяются**: фрагментация, шум, мультиплексирование и тумблер «Проверять сертификат» игнорируются
- **Фильтрация трафика зависит от подписки**, а не от настроек приложения (блокировка рекламы, торрентов)

## Что работает как обычно

Глобальные настройки приложения продолжают работать:

✅ Выбор DNS-серверов  
✅ FakeDNS (если включён)  
✅ Статистика трафика и уведомления  
✅ Автоматическое обновление подписок  

## Редактирование конфигурации

В карточке сервера доступен редактор с двумя режимами просмотра:

- **«Сохранённый JSON»** — настройки, которые пришли из подписки. Здесь можно вручную править параметры
- **«Уходит в ядро»** — финальная конфигурация с добавленными настройками приложения (только просмотр)

> **Внимание:** При сохранении изменений используется исходная конфигурация из подписки. Следующее обновление подписки перезапишет все ручные правки.

## Совместимость

Приложение автоматически исправляет устаревшие форматы конфигураций для совместимости с текущей версией. Это происходит незаметно при подключении к серверу.
